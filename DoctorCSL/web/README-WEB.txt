Help CSL — браузерная версия 1.8.0
==================================

1. Установите Python 3.10+ (https://www.python.org/downloads/).
2. Запустите run.bat (Windows) или:
     python3 -m pip install -r requirements.txt
     python3 web/server.py
3. Откройте в браузере:  http://127.0.0.1:8080

Логин и пароль — те же, что у портала https://h.csl.by

Сервис → Выход стирает сохранённый логин.
Закрытие вкладки данные не удаляет.

Скачать этот архив повторно: в программе «Справка → Скачать веб-версию»
или адрес  http://127.0.0.1:8080/download/HelpCSL-web.zip
