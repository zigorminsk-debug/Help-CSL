# Help CSL

Клиент подачи заявок в Jira Service Desk [h.csl.by](https://h.csl.by).

**Help CSL уже в пути.**

Разработчик: **CSL** (ООО «Компьютерная безопасность», [csl.by](https://csl.by)).

## Для пользователя

1. Для установки на ПК: **HelpCSL-Setup.exe** (рекомендуется) или `HelpCSL-Setup.msi`.
   Ставит в `%LOCALAPPDATA%\CSL\HelpCSL` (без прав администратора), ярлыки и автозагрузку.
2. Введите логин и пароль портала Service Desk и мобильный в международном формате (`+37529…`).
3. Данные сохраняются на этом компьютере. **Сервис → Выход** стирает логин и пароль, поля входа появляются снова. Крестик окна данные не стирает.
4. Выберите вкладку, отметьте типовой инцидент, комментарий справа — и нажмите «Отправить заявку».

| | |
| --- | --- |
| Основной контакт | **+375 29 376-10-95** |
| Время подачи заявок | **09:00–17:30**, рабочие дни по календарю РБ |
| Портал | https://h.csl.by |
| Сайт | https://csl.by |

Вне рабочего окна заявка всё равно уходит в очередь и обрабатывается в ближайший рабочий интервал.

## Версии

Файл `VERSION` + константа в `config.py` + запись в `CHANGELOG.md`.

- `1.0.x` — исправления текущего выпуска
- `1.x.0` — новые функции
- `2.0.0` — ломающие изменения

## Браузерная версия

```bat
py -3 -m pip install flask requests openpyxl
py -3 web\server.py
```

Откройте в браузере адрес, который покажет сервер (по умолчанию `http://127.0.0.1:8080`). Логин и пароль те же, что у портала h.csl.by.

## Сборка из исходников (Windows)

```bat
py -3 -m pip install -r requirements.txt pyinstaller
py -3 -m PyInstaller --noconfirm DoctorCSL.spec
```

Готовый файл: `dist\HelpCSL.exe`.
