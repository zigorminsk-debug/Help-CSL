# История версий Help CSL

Нумерация: **MAJOR.MINOR.PATCH** (semver).

| Разряд | Когда увеличивать | Пример |
| --- | --- | --- |
| PATCH | исправления, тексты, мелкие правки | 1.0.0 → 1.0.1 |
| MINOR | новые функции без ломки совместимости | 1.0.1 → 1.1.0 |
| MAJOR | несовместимые изменения (другой портал, другой формат профиля) | 1.1.0 → 2.0.0 |

Текущий файл версии: `VERSION` и константа `VERSION` в `config.py`. Менять их вместе.
